# 水位管理原型（前端静态包）

解压后启动一个本地静态服务器，即可在浏览器中查看并演示交互；入口默认进入“水位管理 / 模型监控”。

## 最简启动方式

在本文件所在目录执行：

```bash
python3 -m http.server 8080
```

然后在浏览器打开：

`http://127.0.0.1:8080/`

## 说明

- 页面仅使用 Mock 数据，不会调用后端接口。
- 请不要直接双击 `index.html` 打开：浏览器的本地文件安全策略会拦截模块资源加载。
- 如使用其他静态托管工具（Nginx、Vercel、Netlify 等），直接上传本目录全部文件即可。
