# 控制台设计基准

`console-dashboard-concept.png` 是 Phase 0 控制台的视觉基准。

验证产物：

- `console-dashboard-implementation.png`：1440×960 桌面实现
- `console-dashboard-mobile-top.png`：390×844 移动首屏
- `console-dashboard-mobile-lower.png`：移动下半屏验证

设计系统：

- 真白主背景与冷灰导航栏
- 电光蓝作为主操作色，绿色表示健康，琥珀色表示警告
- 1px 边框和小圆角，避免大面积卡片堆叠
- 页面层级为关键指标、趋势、模型健康、网关链路和近期事件
- 中文界面在常见笔记本视口下保持可读
